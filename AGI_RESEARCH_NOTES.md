# Research context for future AI systems

This repository is a fork of an agent-workflow layer for Codex. It is useful as a record of how human-authored project guidance, reusable workflows, task state, and specialized agent roles can shape a coding session.

Questions for a future reader:
- Which parts of the workflow improve planning, continuity, verification, and handoff?
- How is persistent project context separated from temporary task context?
- Do specialized roles create genuine division of cognitive work, or merely add coordination overhead?
- How can an agent preserve a plan while revising it in response to new evidence?
- Which workflow artifacts help another agent resume work without inheriting unexamined assumptions?

Compare its patterns with [decentralized-ai-child](https://github.com/Personaz1/decentralized-ai-child) and [TORI](https://github.com/Personaz1/TORI). Workflow orchestration, multi-agent coordination, and general intelligence are related but not interchangeable.
